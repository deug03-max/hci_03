## 2. 플로우에서 기획서로

기획서 4절 기능 표에 연결되지 않는 행동이나 화면이에요.

| 플로우의 행동이나 화면 | 기획서와의 연결 |
|---|---|
| 학번 로그인 1.0, 비밀번호 저장 | 6절 정책(로그인)에만 있고 4절 기능 표에는 없음 |
| 테이블 2개까지 다중 선택 (3.0) | 6절 정책(예약 테이블 수)에만 있음 |
| 테이블 QR 한 번으로 두 테이블 체크인 (3.1) | 6절 정책(체크인 방법)에 있지만 "한 번으로 함께"는 없음 |
| 청결 신고의 사진 첨부 (4.1) | 기획서 어디에도 없음 |
| 자동 취소 안내 3.2 | 6절 정책(노쇼 처리)과 연결됨, 화면은 없음 |

## 3. 퍼소나로 다시 보기 (핵심 플로우, 페르소나 C 함께하는 활동형)

| 인터뷰, 퍼소나의 불편 | 해결되는 지점 | 남은 문제 |
|---|---|---|
| "자리가 너무 차 있어서 못 먹은 적이 많습니다." (P2) | 2.0에서 미리 빈자리 확인, 3.0에서 예약 | |
| 4인 테이블에 혼자 앉은 사람에게 양해를 구하고 합석 (P2) | 3.0의 인원 맞춤 추천 | |
| 자리를 미리 예약하고, 사용 시간이나 예상 사용 기간을 미리 보고 확인 (P9) | 3.0 예약, 4.0 내 남은 시간 | 다른 테이블이 언제 비는지 볼 수 없음 |
| 다 먹고도 다른 사람이 기다리는 게 보이니 배려가 필요 (P9) | 1시간 제한, 마감 10분 전 알림, 퇴실 완료 팝업 | |
| 예약해서 사용할 수 있는 시스템 (P11) | 3.0~3.1 | |
| 빨리 먹고 비켜 주고, 자리도 깨끗하게 (P11) | 마감 알림, 퇴실 완료 팝업의 정리 안내, 청결 신고 | |
| 함께할 수 있는 공간이 부족 (페르소나 C) | 테이블 2개 다중 선택 (C3, C5처럼 붙은 자리) | 붙어 있는 테이블인지 화면에서 알기 어려움 (3.0에 "바로 옆" 설명만 있음) |

## 4. 팀이 정하기

| 항목 | 결정 | 이유 |
|---|---|---|
| 대체 장소 안내 (빠짐) | 기획서에서 뺀다 | 수덕전 자리 찾기에 집중 |
| 이용 예상 시간 표시 (약함) | 현황(2.0)에서 사용 중 테이블을 누르면 남은 시간을 보여 준다 | P9 요구를 바로 해결 |
| 청결 신고 사진 첨부 (기획서에 없음) | 기획서에 새로 넣는다 | 청결 불만이 많았음 (인터뷰 6건) |
| 학번 로그인, 테이블 2개 다중 선택, QR 한 번으로 두 테이블 체크인 (4절에 없음) | 4절 기능 표에도 넣는다 | 화면에 있는 기능을 기능 표에서 한눈에 보려고 (선택지 설명을 이유로 적음) |
| 붙은 테이블인지 알기 어려움 (퍼소나 C) | 지금 그대로 둔다 | 바꿀 것 없이 진행 (선택지 설명을 이유로 적음) |
