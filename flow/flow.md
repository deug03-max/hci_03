# 서비스 플로우

## 플로우 1: 4명이 함께 먹기 [핵심]
퍼소나: C 함께하는 활동형 / 목표: 친구 4명이 앉을 자리를 미리 확보하고 식사한다
| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | (서비스 밖) 팀이 배포한 QR | 강의실에서 QR을 스캔해 모바일 웹에 들어간다 | 학번 로그인 (1.0) | |
| 2 | 학번 로그인 (1.0) | 학번과 비밀번호를 넣고 로그인을 누른다. 처음 로그인할 때 '비밀번호 저장'을 켜 두면 다음부터는 입력이 채워져 있다 | 좌석 현황 (2.0) | 학번 형식 오류, 비밀번호 틀림: 1.0에 머물며 오류 문구 표시 |
| 3 | 좌석 현황 (2.0) | 종류별 빈자리를 확인하고(사용 중 테이블을 누르면 남은 시간이 보인다) '우리 인원에 맞는 자리 찾기'를 누른다 | 인원과 시간 입력, 테이블 선택 (3.0) | |
| 4 | 인원과 시간 입력, 테이블 선택 (3.0) | 인원 3~4명, 이용 시간을 고르고 추천된 4인석을 선택해 예약하기를 누른다 | 예약 완료 (3.1) | 인원에 맞는 빈 테이블 없음: 자리 없음 팝업 (2.1). 새로고침은 3.0에서 다시 찾기, 이전으로 돌아가기는 2.0 |
| 5 | 예약 완료 (3.1) | 수덕전에 도착해 예약한 테이블 중 한 곳의 QR을 스캔한다. 함께 예약한 테이블도 같이 체크인된다 | 이용 중과 종료 알림 (4.0) | 10분 안에 체크인 안 함: 자동 취소 안내 (3.2), 여기서 '다시 예약하기'는 3.0, '현황 보기'는 2.0. 예약 취소를 누름: 좌석 현황 (2.0) |
| 6 | 이용 중과 종료 알림 (4.0) | 식사하고 마감 10분 전 알림을 받은 뒤 '정리하고 퇴실'을 누른다. 테이블은 빈자리로 바뀐다 | 퇴실 완료 팝업 (4.2) | 불편이 있으면 '불편 신고': 청결 신고 (4.1), 신고하기 후 4.0으로 돌아옴 |
| 7 | 퇴실 완료 팝업 (4.2) | '정리해 주셔서 감사합니다' 안내를 보고 확인을 누른다 (청결 에티켓 강조) | 좌석 현황 (2.0) | |

## 플로우 2: 공강 30분 안에 끝내기
퍼소나: D 빠르게 이동하는 실용형 / 목표: 수업 전에 자리가 있는지 보고, 헛걸음 없이 빨리 먹는다 (인원은 사용자가 정함)
| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | (서비스 밖) 팀이 배포한 QR | 수업이 끝나기 전에 QR을 스캔한다 | 학번 로그인 (1.0) | |
| 2 | 학번 로그인 (1.0) | 저장된 학번과 비밀번호로 로그인을 누른다 | 좌석 현황 (2.0) | 오류: 1.0에 머물며 오류 문구 표시 |
| 3 | 좌석 현황 (2.0) | 종류별 빈자리를 보고 갈지 정한다. 자리가 있으면 '자리 찾기'를 누른다 | 인원과 시간 입력, 테이블 선택 (3.0) | 빈자리가 없어 보임: 서비스를 닫고 다른 곳으로 이동 (서비스 밖) |
| 4 | 인원과 시간 입력, 테이블 선택 (3.0) | 직접 정한 인원, 짧은 이용 시간(20~30분)을 고르고 테이블을 골라 예약한다 | 예약 완료 (3.1) | 맞는 빈 테이블 없음: 자리 없음 팝업 (2.1) |
| 5 | 예약 완료 (3.1) | 이동해서 테이블 QR을 한 번 스캔한다 | 이용 중과 종료 알림 (4.0) | 10분 안에 체크인 안 함: 자동 취소 안내 (3.2) |
| 6 | 이용 중과 종료 알림 (4.0) | 빨리 먹고 '정리하고 퇴실'을 누른다 | 퇴실 완료 팝업 (4.2) | |
| 7 | 퇴실 완료 팝업 (4.2) | 확인을 누른다 | 좌석 현황 (2.0) | |
