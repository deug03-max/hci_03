# 평가 결과 반영 기록

## F1: 시연용 버튼과 글이 참가자에게 보임
- 근거: 클로드 UT 과제 1 단계 1에서 "'오류 모습 보기'는 뭐지?" 하고 멈춤, 과제 3 단계 5에서 "마감 10분 전 알림 예시"라는 글이 보임 (C5, 팀 동의)
- 바꾸기 전: 1.0 '로그인 오류 모습 보기', 1.1 '남은 자리 없음 모습 보기', 3.0 '자리 없음 모습 보기', 3.1 '10분이 지나면 모습 보기' 버튼이 화면 아래에 있었다. 4.0 알림 상자 제목이 '마감 10분 전 알림 예시'이고 "13:05에 알림이 떠요"라는 설명 글이었다.
- 바꾼 뒤:
  - 시연용 버튼 4개를 모두 없앴다.
  - 자리 없음 상황은 시연 데이터로 만든다. 2인석 12개를 모두 사용 중·예약됨으로 바꿔서, 1.1에서 2명을 고르면 '남은 자리가 없습니다'가 저절로 뜨고, 3.0에서 2명을 고르면 자리 없음 팝업(2.1)이 뜬다. 2.1 문구는 "지금은 2명이 앉을 빈자리가 없어요, 가장 빨리 비는 2인석은 B4이고 약 8분 뒤에 비어요"로 맞췄다.
  - 3.1의 체크인 남은 시간이 0이 되면 자동 취소 안내(3.2)로 넘어간다.
  - 4.0 알림 상자를 실제 알림처럼 "이용 마감 10분 전이에요 / 13:15에 이용이 끝나요. 정리를 시작해 주세요."로 바꾸고, 남은 이용 시간을 09:40으로 맞췄다.
  - 3.0의 1명 추천에서 B2 2인석을 A11 창가 1인석으로 바꿨다 (2인석이 모두 찼으므로).
- 고친 파일: design/prototype.html (1.0, 1.1, 2.0, 2.1, 3.0, 3.1, 4.0), ut/plan.md (과제 2 진행 방법)
- 이유: 팀이 "시연용 버튼을 그냥 없애 달라"고 정했다. 사람 UT 과제 2가 계속 가능하도록, 진행자가 버튼을 켜는 대신 데이터로 자리 없음 상황을 만드는 안(2인석 상시 만석)을 골랐다. 이렇게 하면 F3(안내와 배치도가 다르게 보이던 문제)도 함께 없어진다.
