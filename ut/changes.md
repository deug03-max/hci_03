# 평가 결과 반영 기록

## F1: 시연용 버튼과 글이 참가자에게 보임
- 근거: 클로드 UT 과제 1 단계 1에서 "'오류 모습 보기'는 뭐지?" 하고 멈춤, 과제 3 단계 5에서 "마감 10분 전 알림 예시"라는 글이 보임 (C5, 팀 동의)
- 바꾸기 전: 1.0 '로그인 오류 모습 보기', 1.1 '남은 자리 없음 모습 보기', 3.0 '자리 없음 모습 보기', 3.1 '10분이 지나면 모습 보기' 버튼이 화면 아래에 있었다. 4.0 알림 상자 제목이 '마감 10분 전 알림 예시'이고 "13:05에 알림이 떠요"라는 설명 글이었다.
- 바꾼 뒤:
  - 시연용 버튼 4개를 모두 없앴다.
  - 자리 없음 상황은 시연 데이터로 만든다. 2인석 12개를 모두 사용 중·예약됨으로 바꿔서, 1.1에서 2명을 고르면 '남은 자리가 없습니다'가 저절로 뜨고, 3.0에서 2명을 고르면 자리 없음 팝업(2.1)이 뜬다. 2.1 문구는 "지금은 2명이 앉을 빈자리가 없어요, 가장 빨리 비는 2인석은 B4이고 약 8분 뒤에 비어요"로 맞췄다.
  - 3.1의 체크인 남은 시간이 0이 되면 자동 취소 안내(3.2)로 넘어간다.
  - 4.0 알림 상자를 실제 알림처럼 "이용 마감 10분 전이에요 / 13:15에 이용이 끝나요. 정리를 시작해 주세요."로 바꾸고, 남은 이용 시간을 09:40으로 맞췄다.
  - 3.0의 1명 추천에서 B2 2인석을 A11 창가 1인석으로 바꿨다 (2인석이 모두 찼으므로).
- 고친 파일: design/prototype.html (1.0, 1.1, 2.0, 2.1, 3.0, 3.1, 4.0), ut/plan.md (과제 2 진행 방법)
- 이유: 팀이 "시연용 버튼을 그냥 없애 달라"고 정했다. 사람 UT 과제 2가 계속 가능하도록, 진행자가 버튼을 켜는 대신 데이터로 자리 없음 상황을 만드는 안(2인석 상시 만석)을 골랐다. 이렇게 하면 F3(안내와 배치도가 다르게 보이던 문제)도 함께 없어진다.

## F2: 첫 빈자리가 자동으로 골라지고, 시간 선택이나 확인 없이 버튼 한 번에 예약됨
- 근거: 클로드 UT 과제 1 단계 3 ("C3가 벌써 골라져 있네? 내가 고른 건 아닌데... 시간은 안 물어보나?"), 예약 완료에 정한 적 없는 "최대 60분"이 붙음. 과제 3 단계 4도 같은 흐름 (C3, 팀 동의)
- 바꾸기 전: 2.0에서 'OO 바로 예약하기'를 누르면 확인 없이 바로 예약 완료(3.1)로 넘어갔고, 이용 시간은 늘 60분으로 정해졌다.
- 바꾼 뒤: 'OO 바로 예약하기'를 누르면 2.0 위에 확인 창이 뜬다. "이 자리로 예약할까요?", 자리 이름(예: C3 4인석)과 위치(예: 맨 앞쪽, 7열 3행), "얼마나 앉아 있을까요?" 20/30/40/60분(처음엔 60분), '예약하기'와 '다시 고르기' 버튼. '예약하기'를 눌러야 3.1로 가고, 3.1에 고른 시간이 "최대 30분"처럼 나온다. 3.0에서 예약할 때도 3.0에서 고른 시간이 3.1에 나오게 맞췄다.
- 고친 파일: design/prototype.html (2.0, 3.0, 3.1)
- 이유: 팀이 두 안(확인 창, 자동 선택 없애기) 중 확인 창을 골랐다. 자동 선택은 빠르게 예약하는 장점을 살리고, 확인 창에서 자리와 위치를 한 번 보여 주고 시간도 함께 정하게 해서 고르지 않은 자리, 정하지 않은 시간으로 예약되는 것을 막는다.

## 추가: 예약 완료 화면의 위치 안내 지도를 실제 배치도로
- 근거: 팀 요청 (UT 문제 목록에 없는 추가 개선)
- 바꾸기 전: 3.1에 "C3, C5 위치 안내 지도"라고 적힌 회색 자리만 있었다.
- 바꾼 뒤: 예약한 자리 종류의 실제 배치도(4인석 7열 3행, 2인석 3열 4행, 3인석 4열, 좌식 2개, 창가 1인석 한 줄)를 보여 주고, 예약한 자리만 파란색으로 강조한다. 제목은 "4인석 배치에서 내 자리", 위치 설명을 함께 보여 준다. 창가 1인석처럼 긴 배치도는 내 자리가 보이도록 자동으로 내려 준다.
- 고친 파일: design/prototype.html (3.1)
- 이유: 친구와 함께 갈 때 예약한 자리가 어디인지 한눈에 알 수 있게 하려고.
