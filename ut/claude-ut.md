# 클로드 가상 사용성 평가

> 클로드가 퍼소나 역할로 한 가상 평가예요. 결과는 가설이고, 사람 UT로 확인해야 해요.

## 평가 1: 퍼소나 C 함께하는 활동형, 2026-11-27

퍼소나: 친구나 동아리와 함께 공간을 쓰고, 여러 명이 모이는 것을 좋아한다. 함께할 수 있는 공간이 부족한 것이 불편하다. 기기 사용 수준은 퍼소나 자료에 없어서 가정하지 않았다.
기준: `design/prototype.html` 의 2026-11-27 버전, 휴대폰 크기(390×844)로 화면에 보이는 글과 버튼만 근거로 움직였다.

## 화면 점검
과제에서 지나간 화면(1.0, 1.1, 2.0, 3.1, 4.0)만 봤다.

1. 지금 무슨 일이 일어나는지 보이나요? 예약하면 "OO를 예약했어요" 안내와 예약 완료 화면이 나와 분명하다. 다만 2.0에서 자동으로 골라진 자리가 테두리로만 표시돼 "내가 고른 것"인지 알기 어렵다 (C3).
2. 사용자가 쓰는 말인가요? '예시', '모습 보기' 같은 시연용 말이 섞여 있다 (C5). 나머지는 학생이 쓰는 말이다.
3. 잘못 눌렀을 때 돌아갈 수 있나요? 1.1에서 인원을 잘못 골랐을 때 2.0에 1.1로 돌아가는 버튼이 없다. 칩으로 다른 종류를 볼 수는 있다.
4. 같은 것은 같은 모양과 같은 이름인가요? 하단 버튼이 상황에 따라 예약 버튼이 되었다가 상태 안내가 되었다가 해서 같은 자리에 다른 역할이 섞인다 (C2).
5. 실수하기 전에 막아 주나요? 바로 예약하기에 확인 단계가 없다 (C3). 예약 완료 화면에 '예약 취소'가 있어 되돌릴 수는 있다.
