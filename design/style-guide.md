# 수덕자리 스타일 가이드

## 느낌
빠르다, 분명하다, 가볍다
- 이유: 공강 30~40분 안에 먹어야 하는 페르소나 D, 함께 앉을 자리를 빨리 잡아야 하는 페르소나 C. 빈자리 여부와 남은 시간이 한눈에 보여야 한다.

## 색
| 이름 | 색상 코드 | 쓰는 곳 |
|---|---|---|
| 주색 (남색) | #1f3a8a | 주요 버튼, 선택됨, 상단 서비스 이름 |
| 주색 진하게 | #172c6b | 버튼을 누를 때 |
| 강조 (코랄) | #e8553f | 마감 알림 배경, 강조 표시. 글자로 쓸 때는 진한 코랄 #b93a26 |
| 배경 | #ffffff | 화면 바탕 |
| 바탕 회색 | #f4f6f9 | 카드 바깥, 구역 구분 |
| 글자 | #1b2230 | 본문 |
| 보조 글자 | #4a5363 | 설명, 시간 (흰 배경에서 대비 7:1 이상) |
| 선 | #d9dde5 | 카드 테두리, 구분선 |
| 상태: 비어 있음 | 바탕 #e7f5ec, 테두리 #1e7b45 | 배치도의 빈 테이블 |
| 상태: 사용 중 | 바탕 #5b6472, 글자 흰색 | 배치도의 사용 중 테이블 |
| 상태: 예약됨 | 바탕 #fff1ec, 점선 테두리 #b93a26 | 배치도의 예약된 테이블 |

- 상태 색은 색만이 아니라 밝기와 테두리 모양(실선, 점선)으로도 구분한다.
- 연한 회색 글자를 흰 배경에 쓰지 않는다. 보조 글자는 #4a5363 이상으로 진하게.

## 글자
기본 글꼴: 휴대폰 기본 고딕 (애플 산돌고딕, 맑은 고딕, system-ui). 숫자는 굵게, 자리 폭을 맞춘다(tabular-nums).
| 단계 | 크기, 굵기 | 쓰는 곳 |
|---|---|---|
| 큰 숫자 | 32px, 800 | 빈 테이블 수, 남은 시간 |
| 제목 | 22px, 700 | 화면 제목 |
| 소제목 | 17px, 700 | 구역 이름 |
| 본문 | 16px, 400 | 기본 글 |
| 보조 | 13px, 400 | 설명, 안내 |

## 모양
- 모서리 둥글기: 카드, 입력칸 12px / 버튼 12px / 칩 999px
- 버튼: 높이 52px(주 버튼), 44px 이상(그 밖). 주 버튼은 남색 바탕에 흰 글자, 보조 버튼은 흰 바탕에 남색 테두리와 글자.

## 기본 부품
- 상단 바: 서비스 이름 또는 뒤로 + 화면 제목, 오른쪽에 기준 시각
- 주 버튼, 보조 버튼
- 입력칸 (학번, 비밀번호)
- 체크 상자 (비밀번호 저장, 테이블 선택)
- 카드 (예약 정보, 상태 안내)
- 칩 (종류별 빈자리, 인원 선택)
- 배치도 테이블 칸 (비어 있음, 사용 중, 예약됨)
- 팝업 (자리 없음, 퇴실 완료)
- 하단 메뉴는 쓰지 않는다 (와이어프레임에 없음)
